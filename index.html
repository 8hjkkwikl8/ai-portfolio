01 · FLAGSHIP检索增强生成

InsightRAG

可追溯的中文企业知识库问答与金标评测。检索、证据回放、回答和指标均可独立检查。

TXT 文档→字符偏移分块→BM25 + 哈希/嵌入向量→RRF→引用校验

工程亮点

  • SQLite 持久化与重复来源整体替换，避免重复语料。
  • 每个证据保留 source、chunk_id 与原始字符区间。
  • 可插拔嵌入适配器：默认离线哈希向量，配置环境变量后切换 OpenAI 兼容嵌入，分块向量带缓存。
  • 在线生成逐句过滤非法或无编号内容，失败回退离线摘要。
  • Recall@k、MRR、引用编号合法率、人工忠实度、延迟与 Web UI。

设计取舍

默认使用可复现的轻量哈希 n-gram 向量，不冒充神经语义嵌入；神经嵌入需显式配置，未配置时绝不联网。引用编号合法率也不等于语义忠实度；人工忠实度只对 6 条已审阅的离线快照按回答指纹计分，其余记 N/A。这样牺牲一部分语义能力，换来零依赖演示和明确可审计边界。

02 · LIGHTWEIGHTLLM 评测工程

PromptLens

不可变提示词版本、JSONL 数据集、可复现实验与单文件 HTML 对比报告。

内容哈希版本→批量运行→指标 / 标签→Delta 报告
  • 严格模板变量、数据 SHA256、运行清单与复现哈希。
  • exact / contains / regex，失败隔离、超时与有限重试。
  • 永久性 4xx 不重试，保留字段不能覆盖审计请求。
  • 可选定价配置输出成本估算与对比，明确标注为估算值。
  • 同配置重复运行输出均值/极差，明确声明非统计显著性。
  • 所有动态报告内容 HTML 转义，防注入。

Mock 只验证评测流水线，不能作为真实模型质量提升证据；真实结论需要 API 与独立留出集。

03 · LIGHTWEIGHTAI + 数据安全

DataChat BI

自然语言到安全 SQL 的只读电商分析，带中文 Web UI 和内联 SVG 图表。

规则 / LLM 候选→SQL 守护→只读 SQLite→SVG 报告
  • 单 SELECT / WITH、三表白名单与受控 JOIN、列校验、参数绑定与行数上限。
  • 只读 URI、query_only、authorizer 和进度处理器超时。
  • 本地 JSONL 查询审计，只保存 SQL 哈希，不保存参数原文。
  • 规则问法完整匹配，额外筛选条件不会被静默忽略。
  • 48 行确定性订单 + 两张维度表、9 类问题、8 幅图表。

离线模式仅支持显式分析问法，不宣称理解任意自然语言；LLM 也只提供候选 SQL，必须统一通过守护。
